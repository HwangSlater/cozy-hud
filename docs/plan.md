## 무엇을 만드나
Claude Code mod 모음 저장소 **cozy-hud**(공개). 하나의 mod 가 아니라, 코어 위에 부품과 꾸미기 팩을 골라 끼우고 언제든 바꿀 수 있게 한다.

```
cozy-hud/                       저장소 = 마켓플레이스 (.claude-plugin/marketplace.json)
├─ core/          필수. $.hud 를 더한다: 패널·입력창 위 줄을 그리는 틀, 테마·캐릭터 엔진,
│                 기분(평소/일함/끝/경고/잠) 계산, 배치·테마 고르기 명령(/hud …), 고른 값 저장($.store)
├─ widgets/<이름>/ 부품. core 에 dependencies 로 기대고, 자기 칸만 등록한다(그리기·배치는 core)
└─ packs/<이름>/   꾸미기 팩. 캐릭터 픽셀·팔레트 데이터만, 코드 거의 없음
```

## 만들며 알게 된 것
- 부품 → 코어 호출(`$.hud.put`)은 「이벤트」라 넘기는 값이 순수 데이터뿐이다. 그래서 부품은 그리기 함수가 아니라 카드 데이터(줄·색 역할)를 보낸다.
- `$` 를 받는 도우미 함수는 파일 최상위에 선언해야 검증을 통과한다. atom 의 plugin·key 는 글자 그대로 적어야 한다.
- 캐릭터는 터미널에서 `Raster` + `$.ui.blit` 로 칸만 바꿔 끼워 움직인다(다시 그리지 않음).
- 움직임 타이머는 엔진에 값을 묻지 않는다: 설정·캐릭터·기분을 mem 에 사본으로 들고, 자세(눈 뜸/감음, 일하는 프레임 등)별 그림을 한 번만 계산해 둔다. 같은 자세면 아무 일도 안 함. 잠들었거나 「멈춤」이면 타이머 자체가 없다. 가만히 있는 2.5초 동안 엔진 읽기 40번 → 0번(시험으로 확인).

사용자가 고른 여덟 가지. 화면이 바뀌는 것은 시안(로컬 `make-mods-시안\고도화\새기능시안.txt`)을 고른 뒤 적용한다.
- [x] 할 일 카드: 파일 칸을 비우면 세션 체크리스트 파일(`{home}/.claude/checklists/{session}.md`)을 자동으로 따라감(이 빌드에는 할 일 도구가 없음)

- [ ] 서브에이전트 표시 · 캐릭터 쓰다듬기 · 하루 기록·레벨(기본 끔)

- 불만: 좁은 터미널에서 잘림(claude-hud 이슈 #172) → 우리는 크게·보통·작게 모양으로 대응.
- 알림: 끝남(Stop)과 승인 필요(permission) 두 가지, 소리를 선호.
- 캐릭터: 쓰다듬기·반응은 좋아하나 레벨·성장은 「산만하다」는 반응이 많음(/buddy 반응) → 조용함이 기본, 끄기 필수.
- 서브에이전트: 에이전트마다 이름·하는 일·걸린 시간 한 줄(claude-hud), 개수 표시 요청이 많음.
