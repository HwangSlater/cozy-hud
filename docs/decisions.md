# 결정

> 최종 수정: 2026-11-04 · 구성·이름·캐릭터를 왜 그렇게 정했는지

## 구성: 코어 + 부품 + 꾸미기 팩 (2026-11-02)
- 하나의 mod 에 다 넣지 않고, 사용자가 부품을 골라 설치하고 배치·테마·캐릭터를 언제든 바꾸게 한다.
- 부품은 칸만 등록하고 그리기·배치는 코어가 맡는다 → 여러 부품이 한 패널에 섞여도 디자인이 하나로 맞는다.
- 근거: mod 는 `engine.create` 에서 `$` 에 noun 을 더할 수 있고, 다른 mod 가 `dependencies` 로 그 타입·기능을 받는다. 마켓플레이스 파일 하나에 mod 여러 개를 올릴 수 있다.
- 버린 안: 단일 mod + 켜고 끄기(필요 없는 기능까지 깔리고 커질수록 고치기 어려움), 완전히 따로 노는 mod 들(디자인·캐릭터를 공유 못 함).

## 이름: cozy-hud, 공개 저장소 (2026-11-02)
- 게임에서 화면 위 정보 표시를 HUD 라 부르는 관행 + 아늑한 캐릭터 느낌. 명령 접두어는 `/hud`.

## 설정은 패널에서 (2026-11-03)
- 고를 것이 많아 `/hud` 명령만으로는 불편하다는 사용자 의견. `/hud` 는 설정 패널을 열고, 탭(캐릭터 · 배치·말풍선 · 테마 · 카드)에서 버튼·목록으로 고른다. 명령(`/hud character mochi` 등)은 빠른 길로 남긴다.
- 고를 수 있는 것: 캐릭터, 크기(패널·입력창 위 따로), 움직임 속도, 잠드는 시간, 도구 말풍선(파일 이름까지·하는 일만·끔), 끝냄·경고 반응, 배치, 테마, 카드 순서·숨김, 카드별 설정(부품이 `options` 로 내놓음).
- 카드별 설정은 부품이 카드에 항목을 실어 보내고, 코어가 고른 값을 `hud.option` 으로 돌려준다. 부품 → 코어, 코어 → 부품 모두 순수 데이터만.
- 화면 배치(사용자와 여러 번 고쳐 정함): 「HUD」·「HUD 설정」 두 탭을 늘 같이 연다(설정을 HUD 패널 아래에 붙이는 것은 사용자가 원한 것이 아니었음). 설정 탭 아래에 테두리 상자로 미리보기를 두고, 캐릭터 넘기기(◀ 이름 순번 ▶)는 미리보기 캐릭터 **밑 줄**에 둔다.  그림 격자·그림 옆 버튼은 써 보고 버렸다.
- 맨 위 한 줄(2026-11-03, 시안 1번): 오른쪽 끝에 「초기화」(누른 뒤 같은 자리에 「되돌리기」). 왼쪽 키보드 안내는 2026-11-04 사용자 「키보드 없애자」로 뺐다(좁은 패널에서 세 줄을 차지). 단축키(1~4, A/D)는 그대로이고 안내는 README 에만. 「처음 설정으로」는 「초기화」로 이름을 바꾸고 맨 아래 줄은 없앴다. ⌨·→ 같은 기호는 터미널에 따라 두 칸이 돼 글자로 쓴다.
- 카드 순서 목록 줄 아래에 그 카드의 한 줄 요약(입력창 위 줄과 같은 것)을 흐리게 붙인다(시안 2번) — 미리보기가 아래에 있어 순서를 바꿔도 잘 안 보인다는 사용자 의견.
- 카드 탭(2026-11-03, 시안 3개 중 2번): 위에 「보일 카드와 순서」(순번 · `[✓카드 이름]` 보이기 칸 · 위 · 아래, 맨 위·맨 아래의 위·아래도 흐리게 남겨 줄 고정), 아래에 보이는 카드마다 묶음 제목 + 설정. 숨긴 카드의 설정은 접고 한 줄로 알린다. 글자 설정은 이름 · 안내 · 입력칸을 줄마다 나눠 안내가 잘리지 않게. 화살표(↑↓)는 터미널에 따라 두 칸이 돼 「위」·「아래」 글자로.
- 두 탭은 닫을 수 없다(2026-11-03, 사용자: 닫기를 누르면 맨 위 탭이 안 뜬다 → 방지): 「닫기」 버튼을 빼고 `✕` 도 막는다. HUD 탭은 「보일 곳 → 입력창 위만」일 때만 닫힌다. 엔진이 내린 탭은 답변이 끝날 때 되살린다.
- 숫자 1~4 로 탭을 바꾸고, 맨 위에 키보드 안내 한 줄. Esc 는 설정 탭을 닫지 않고 키보드만 돌려준다.
- HUD 모양(2026-11-04, 사용자: 패널을 최소로 줄여 쓰는데 그 상태에 맞는 것도 / 크게·보통·작게를 누르면 각자 맞는 설정만): 설정에 `form`(크게 · 보통 · 작게)을 두고 탭을 「1 모양 · 2 배치 · 3 테마 · 4 카드」로. 모양 탭은 버튼 한 줄 + 한 줄 설명(시안 2 → 변주 2-2), 그 아래 고른 모양에서 쓰는 설정만(탭은 같은 날 아래 두 단계 목록으로 바뀜).
  - 크게(50칸 이상): 캐릭터 크게·보통, 카드 + 세부 줄(`detail`: 남은 공간, 세션 입력·캐시), 막대 48·할 일 12 까지.
  - 보통(32~50칸): 캐릭터 보통·작게, 지금 카드.
  - 작게(22~32칸): 캐릭터 작게·숨기기, 말풍선 하는 일만·끄기, 카드 대신 가로줄 아래 「이름 · 값」 줄(`compact`, 없으면 제목 · 한 줄 요약). 보일 줄을 하나씩 켜고 끈다(`hiddenRows`).
  - 모양과 상관없는 것(보일 곳, 입력창 위 크기, 움직임, 반응)은 2 배치로. 4 카드는 순서·숨김만.
  - 모양을 바꿔 지금 값이 없으면 전체 순서에서 가장 가까운 값으로(크게 → 작게면 캐릭터 「작게」, 파일 이름까지 → 하는 일만). 카드 설정도 `forms` 를 단 항목·값은 같은 규칙으로 부품에 알린다.
  - 모양이 없던 예전 설정은 패널 크기가 크게면 「크게」, 아니면 「보통」으로 읽는다.
  - 어느 모양이든 게이지는 패널 폭에 맞춰 줄이고 막대그래프는 최근 것만 남긴다(좁은 패널에서 넘치던 것). 캐릭터 없이 말할 때는 상자 없이 「▸ 하는 일」 한 줄.
- 설정을 두 단계 목록으로(2026-11-04, 사용자: 타고 들어가는 식으로 해 미리보기를 늘 보이게 → 시안 2 → 변주 2-3, 경로 칸을 누르면 그 단계로 바로): 미리보기를 설정 탭 맨 위로 올리고, 그 아래는 처음 목록(모양 › · 배치 › · 테마 › · 카드 ›) → 묶음 목록(「캐릭터  작게 ›」처럼 지금 값을 붙임) → 항목 쪽. 항목 쪽은 고를 것을 한 줄에 하나씩 세우고, 고른 뒤에도 머물러 미리보기로 비교한다. 맨 위 경로 「설정 › 모양 › 캐릭터」의 앞 칸은 버튼이라 누르면 그 단계로 바로 가고, 초기화는 처음 목록에서만 보인다. 탭(1 모양 · 2 배치 …)은 없앴다. 테마·카드는 한 쪽짜리.
- 설정 쪽 모양(2026-11-04, 사용자: 안 예쁘고 구분이 안 간다 → 시안 3개 중 1번 「설정 앱 목록」): `[ ]` 테두리 버튼 대신 테두리 없는 버튼(`plain`). 경로 앞 칸은 강조색 글자, 지금 쪽은 굵게, 경로 아래·목록 끝에 얇은 가로줄. 목록 줄은 이름 왼쪽 · 지금 값과 › 흐리게 오른쪽 끝. 고르기는 고른 줄에 강조색 ✓ + 굵은 글자(시안의 ●○ 는 터미널에 따라 두 칸이라 ✓). 「‹ 뒤로」 줄은 없애고 경로 앞 칸이 대신, 목록 숫자 키도 뺐다(테두리 없는 버튼에 숫자 키를 달면 「1: 」가 붙음). 초기화는 흐린 글자.
- 미리보기의 캐릭터 넘기기 줄은 좁으면(이름 칸 + 18칸 미만) 이름 버튼을 위 줄에, `[ < ] 순번 [ > ]` 를 아래 줄에 — 한 줄에 넘쳐 빈 줄로 보이던 것. 카드 한 줄은 Text 하나로 감싸 줄 끝에서만 자른다(조각마다 잘려 「이번 답변…출…」이 되던 것).
- 고르기(2026-11-03, 사용자 「< > 클릭이 빡세다」·「눈에 보이는 게 아쉽다」): 선택지 5개 이하는 펼치는 목록 대신 버튼 줄(한 번 클릭), 고른 버튼에 `✓`. 버튼 줄이 이름 옆에 안 들어가면 이름 아래에 들여 쓴다. 묶음 제목+가로줄(모양·움직임 / 배치·말풍선) — 시안 3개 중 1번. 캐릭터 넘기기는 테두리 버튼 `[ < ]` `[ > ]` + 단축키 A/D. 캐릭터 전체 목록도 설정 탭에서 빼 넘기기 줄의 이름 자리(`[ < ]  곰 ▾  [ > ]`)로 옮김 — 시안 3개 중 1번.

## 3단계 새 기능 (2026-11-04)
사용자가 「알아서 추천」으로 맡겨, 조사 결과(docs/plan.md)에 맞춰 시안(로컬 `make-mods-시안\고도화\새기능시안.png`)에서 골랐다.
- 사용량 A-1(한도 게이지 + 리셋까지 남은 시간): 가장 많이 원한 정보이고, %만으로는 쓸모없다는 의견이 있어서. 비용은 설정에서 숨길 수 있다(구독 사용자는 비용보다 한도를 봄).
- 도구 기록 B-1(시간순, 실패는 경고색), git C-1(요약 + 바뀐 파일), 서브에이전트 D-2(카드만, 에이전트가 없으면 카드를 내림, 끝난 것은 10초 뒤 사라짐).
- 쓰다듬기 E-1(캐릭터 밑 버튼): 캐릭터가 그림 칸(Raster)이라 그림 자체를 누르게 하기 어렵고, 버튼이 누를 수 있다는 걸 보여 줌. 배치에서 숨길 수 있다.
- 오늘 기록 F-1(레벨 없음, 기본 끔): 레벨·성장은 「산만하다」는 반응이 많아서.
- 카드 넷은 따로 설치하는 부품(cozy-hud-usage·tools·git·agents), 쓰다듬기·오늘 기록·끝남 알림은 코어. 「알림」 목록은 「알림·기록」으로.
