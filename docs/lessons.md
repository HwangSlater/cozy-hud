## 매 틱 전체 다시 그리기는 무겁다

- mod 에서도 같다: 타이머로 다시 그릴 때 바뀐 값만 atom 에 쓰고, 보이지 않는 패널은 갱신하지 않는다.

## 고친 뒤 숫자가 너무 좋으면 먼저 의심한다
- 고친 줄이 실제로 반영되지 않아 그리기가 매번 오류로 멈췄는데, CPU 숫자만 보고 좋아졌다고 착각할 뻔했다. 화면 안에서 직접 계측(오류·갱신 줄 수)해 원인을 찾았다.

## 헤드리스 스크린샷
- `--virtual-time-budget` 로 찍으면 IntersectionObserver·타이머가 실제처럼 돌지 않아 빈 화면이 나온다. DevTools 프로토콜로 실제 시간을 기다린 뒤 `Page.captureScreenshot` 으로 찍는다.
